# TEAZ

**Seu estilo, seu universo.** Uma boutique digital para descobrir peças, explorar estilos e criar combinações.

## Stack
- Next.js 15 + React 19 + TypeScript
- CSS responsivo com identidade blush, champagne e dourado
- API route para TEAZ AI (OpenAI Responses API, opcional)
- Esquema inicial Supabase em `supabase/migrations/001_init.sql`

## Começar
```bash
npm install
cp .env.example .env.local
npm run dev
```
Abra http://localhost:3000.

Leia [docs/SETUP.md](docs/SETUP.md) antes de publicar. O catálogo inicial é demonstrativo: preços, imagens e links não são ofertas verificadas. O painel no navegador é apenas um protótipo local, não um painel seguro de produção.
